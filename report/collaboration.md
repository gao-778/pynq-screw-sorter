# 大模型协作摘要

记录类型：实际需求与执行摘要。完整原始对话不由本文件代替。

需求包括：按自主选题初级组目录交付，复用指定的通用 skills，将裸机 C 和 PYNQ 统一为一个工程，面向项目使用者编写 README，并检查源码、模型、硬件、产物和开源文件对应关系。

工程决策：以一份 C 业务核心服务两种运行方式，使用明确的平台接口管理时间、文件、内存和控制台；两种目标从同一构建配置取源，使用同一模型与 RTL；公开文件范围由依赖清单和许可声明定义。

执行验证：分别编译两种平台，运行共享生产状态机、API、协议与运动、坐标及 RTL 检查，核对模型各表示和 BOOT 的完整分区，执行从源码的工程/IP 重建和发行清单核验。记录分别保存在 sim/results/、build/reports/ 和 validation.json。
