# 接口契约

目标器件：xc7z020clg400-1。模型：MC18。PYNQ ABI：0x50594d32；模型 ID：0x4d433138。工程参数见 ../build/project.json，硬件完整地址映射见 ../board/overlay_contract.json。

| 窗口 | 基址 | 大小 |
|---|---|---|
| 控制 GPIO | 0x41200000 | 64 KiB |
| 识别寄存器 | 0x42000000 | 64 KiB |
| UI 寄存器 | 0x43000000 | 64 KiB |
| 灰度 DMA | 0x40400000 | 64 KiB |
| 截图 DMA | 0x40410000 | 64 KiB |
| 舵机 UART | 0x43c00000 | 64 KiB |
| 舵机 GPIO | 0x41210000 | 64 KiB |

识别窗口偏移：0x94 灰度基址、0x98 预览基址、0x9c ABI、0xa0 地址有效、0xa4 预览运行、0xa8 主设备空闲。设置地址后才使能生产者。关闭时停止任务和生产者，等已接受的 AXI 请求与响应排空后释放内存。

裸机保留地址：灰度 0x10000000/4 MiB、预览 0x11000000/768 KiB、截图 0x11400000/3686400 字节。链接脚本把应用限制在 0x08000000 以下。PYNQ 由 allocate 分配相同容量，向共享 C 分别绑定设备地址与 CPU 虚拟指针。

共享 C ABI 在 ../src/common/screwsort.h；平台 ABI 在 ../src/platform/。结果只能在状态有效时用于控制；每次动作以新场景重新选择目标。
