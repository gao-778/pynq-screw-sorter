# 裸机平台适配清单

| 裸机依赖 | Linux/PYNQ 适配问题 |
|---|---|
| Xil_In32 / Xil_Out32 | 映射区间、访问宽度、顺序、所有权、越界处理 |
| 固定 DDR / 链接保留区 | allocate、设备可达范围、生命周期、RTL 动态基址 |
| 强转物理地址的指针 | 绑定虚拟指针与设备地址，按区间做转换 |
| BSP 缓存 API | 由对应缓冲区的缓存同步 API 实现，区分方向 |
| 裸机 tick / sleep | 单调时间、单位、回绕、最坏服务间隔 |
| FatFs | 文件路径、错误码、同步时机与已有文件策略 |
| PS UART 控制台 | Linux 设备所有权，使用命令队列或明确的串口接口 |
| 处理器复位寄存器 | 应用退出与系统关机分别定义 |
| 中断 | Linux/PYNQ 可用中断机制，避免重复驱动 |

## C ABI 轮廓

下面是接口职责示意，不是固定名称要求：

```c
int initialize(const struct platform_config *config);
int service(void);        /* 有限工作量，说明期限要求 */
int request_cancel(void); /* 明确异步完成条件 */
int snapshot(struct application_state *out, size_t bytes);
int shutdown(void);       /* 未排空时返回原因，不释放活跃内存 */
```

Python 侧分别管理硬件加载、缓冲区、C 库、后台任务、命令队列、状态与退出。C 输出结构的大小、字段对齐、整数和指针位宽必须对应目标 ABI；共享库必须与运行平台 libc、架构及浮点 ABI 兼容。
