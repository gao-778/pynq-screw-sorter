# MC18 模型与训练产物

部署模型识别 15 类螺丝和 3 类螺母，使用 **255,912 个可训练参数**。模型训练在 PC 上完成，量化参数由 PS 上传到 FPGA，CNN 推理在 PL 执行。训练源码说明见 [training/README.md](../training/README.md)。

## 结构与整数约定

| 项目 | 配置 |
|---|---|
| 输入 | 64×64 单通道 ROI，加 3 项几何特征 |
| 卷积 | 三层 3×3，通道 1→32→96→256，dilation=2、padding=2 |
| 特征 | 深层 GAP 256 + 中层池化前 GAP 96 + 几何 3 = 355 |
| 分类头 | 355→18 |
| 权重 | 255,510 个 INT8 |
| 偏置 | 402 个 INT32 |
| 激活移位 | `[6,6,6]`；三项移位配置不计为可训练参数 |
| 参数合计 | 255,510 + 402 = 255,912 |
| 推理 ABI | MC18，ID `0x4D433138`；CNN 32 条 MAC 通路 |

该模型包含扩大后的旧 V2 特征通道、量化分类头训练和保守联合微调。不能把所有扩展通道都称为完全独立从零学到的特征，也不能仅用参数数量推断识别精度。逐层真实整数更新记录在模型导出的 `weight_change_report.json`。

### 必须保持一致的预处理

完整契约以模型清单及 RTL 为准，核心规则如下：

1. 输入是 1280×960 原始灰度帧，不能用带 UI 的 HDMI 截图训练。
2. 在 `gray[4::8,4::8]` 上统计直方图，`T=clamp(P90+max(8,3×(P90-P50)),40,220)`。同一帧的连通域、矩、几何和前景遮罩使用同一阈值。
3. 使用包含端点的 AABB、安全边长 `ceil(sqrt(w²+h²))` 和 Q8 系数，按 180° 内 16 档进行方向归一化。ROI 采样按硬件整数取整规则，AABB 或图像外填 0。
4. ROI 灰度右移一位。几何特征为饱和到 127 的 `projected_length>>1`、`2×max_end_width`、`2×min_end_width`。
5. 使用模型指定的权重顺序、偏置顺序、定点缩放和溢出规则，不能拿任意框架的默认浮点推理直接当作硬件结果。

这个分类器依赖前级候选检测。测试 ROI 准确率高，不代表严重粘连、遮挡或陌生零件也能被完整检测。

## 数据和训练思路

训练资料记录了 2,072 张旧螺丝原图以及 332 张新旧螺母原图；两张手部遮挡螺母图被隔离，330 张可用螺母图筛出 2,505 个有效螺母实例。原始照片、标注清单和大缓存未随此源码仓库公开。

旧螺丝保持原冻结划分。螺母按类别和来源分层，并把相近前景布局归入同一组再划分 train/val/test，降低近似摆放泄漏。标注结合单类文件夹、前景几何筛选和联系表审查，不是每个像素均由人工描边。

光照增强改变整帧亮度、gamma、遮光梯度和噪声后，再执行阈值、连通域和裁剪；旋转/位置增强也遵守硬件采样契约。这样训练看到的是硬件可能产生的 ROI，而不是任意修图结果。

联合微调固定旧 15 类分类头行，训练卷积和新增螺母分类头，结合旧模型教师分数约束及验证集保护门槛。最终模型由验证集选定，测试集在本轮冻结之后评估；旧螺丝测试集历史上已使用，不能称为全新盲测。

## 部署文件各自的作用

| 文件 | 用途 |
|---|---|
| `best_qat.pt` | PC 端 QAT checkpoint，不直接放进 FPGA |
| `quantized_model.npz` | 量化权重、偏置、移位、类别及结构元数据 |
| `weights.hex` / `biases.hex` / `shifts.hex` | 权重 2 位十六进制、偏置/移位 8 位十六进制，按固定顺序逐行保存 |
| `model.bin` | FNET-v1 参数交换格式；含数量和 CRC，不是板卡启动文件 |
| `shape_model.h` | 当前裸机程序编译时内嵌的参数数组，启动时经 AXI 上传 |
| `reference.py` | 独立 NumPy int64 推理参考；不是训练入口，也不在板上承担实时 CNN |
| `model_manifest.json` | 模型结构、预处理契约、类别顺序和哈希 |

`model.bin` 的头部为 24 字节：`FNET`、版本、权重数、偏置数、移位数、payload CRC32，整数按 little-endian 存储。为了匹配 32 位参数写入接口，每个导出参数槽占 4 字节，所以当前文件是 1,023,684 字节；这不代表每个卷积权重在 PL 中占 32 位。按 INT8 权重、INT32 偏置和三个 INT32 移位紧凑计算为 257,130 字节，实际 BRAM 占用还包含特征图、端口和存储组织开销。

只把新 PT、NPZ 或 `model.bin` 放到 SD 卡根目录，不会自动替换当前模型。应完成格式/整数对齐验证，替换活动软件中的 `shape_model.h`，用匹配的 MC18 硬件重新构建 ELF 和 BOOT。扩大层数、通道或类别时还要同步修改 RTL 和 ABI。
