# 标定示例

这里的矩阵和原点是原工作台的测量结果，供检查坐标约定。换相机位置、平台或原点后必须重新标定，不能直接把示例矩阵当成通用值。

`calibrate_platform.py` 是原始标定过程的参考脚本，使用 40、80、120 mm 三个同心正方形及黑点。脚本中的帧文件名和角点搜索种子对应当时照片；该原始 USB 帧没有公开，因此本目录不是自动识别任意标定纸的一键工具。用于新装置时，需要自己的原始帧并重新提供角点种子；预览图使用本机安装字体，不携带字体文件。

可以在无需原照片和板卡的情况下，核对当前软件的 OBB 中心、长轴方向和毫米换算：

```powershell
python calibration/test_obb_coordinates.py
```

此检查需要 NumPy 和 GCC；32 个算例覆盖 16 个旋转档位及两种长轴方向。结果写到 Git 忽略的 `build/obb_coordinate_test/`。它验证坐标计算一致性，不验证相机镜头误差、实际测量精度或夹取落点。
